# Changes in v1.0.15

## On-demand Windows client

- Added separate sing-box client manager; does not alter v1.0.14 scanning/ranking algorithms.
- Connect **any one selected supported node** or a rank within an existing saved JSON shortlist.
- Local mixed HTTP/SOCKS5 listener (loopback-only), Windows per-user system proxy, and administrator-only Windows TUN.
- System-proxy backup and conditional restore; crash-recovery support while respecting changes from other applications.
- Windows Job Object terminates sing-box if the GUI crashes; no orphan persistent client is intended.
- Real HTTPS Test connection button, manual proxy URL copy, explicit Disconnect/cleanup, core validation before client launch.
- Scanner prevents running a full benchmark while its own TUN is active; source updates remain possible.
- Expanded GUI, tooltips, settings, source-package version and Windows release build metadata.

## Unchanged

- Latency testing, flow-rate measurement, speed candidate selection, scan presets, scheduled monitoring, 3-category exports, and automatic Android BPF generation.

## Limitations

- Single-node client only, not a full Karing-style rule-routing implementation.
- Windows system proxy is not all-traffic tunneling; TUN requires administrator rights and hasn't been tested with Win11 on an Iranian network.
- Windows Setup.exe is generated by the included GitHub Actions workflow; this source ZIP is not that executable.
